The ordinary result's Details and the unlocked assembly exports expose a lazy animation panel. Free result animation reveals the existing free preview, not the locked numeric guide. It never includes original photographs, a target overlay, generated facial features, audio or camera/microphone input. Existing instructions, engines, hashes, numerical steps and entitlement rules are unchanged.

Every frame is an ordered prefix of the immutable sequence, including an empty first frame and the complete final frame. Reference2/LS3/accent use the same1000px physical raster with an explicit incremental state; legacy guides use the existing renderer and its existing resolution/padding through an OffscreenCanvas surface factory. The existing renderer's default DOM surface and arithmetic are unchanged. No list of full-resolution frames is retained.

Canvas capture uses explicit frame requests and an actually supported MediaRecorder MIME, selected in order WebM/VP9, WebM/VP8, WebM, MP4. A nominal6second progression plus final hold yields about7seconds; render/encode time can extend it. Real-time browser capture can duplicate/drop presentation frames, and its codec is lossy; the renderer's final frame must exactly match the app preview. A positive capability probe is not a guarantee of encoder resources. Unsupported/failed video offers an explicit GIF alternative rather than a renamed PNG or fake MP4.

The original bounded GIF89a writer emits actual320px palette frames, a loop extension, per-frame delays and a valid LZW stream with periodic dictionary clears. The Worker computes explicit area averages of the physical raster, avoiding backend-dependent canvas downscaling/readbacks. Grayscale has256gray entries; colored guides use a3/3/2 palette and visibly reduced colors. It is an animation, not a lossless substitute for the full-resolution preview. GIF requires no capture/MediaRecorder support and works offline after shell precaching.

Cancellation, navigation/unmount, inactive customer flow and page hiding abort the job. Worker termination, recorder stop, every capture track and watchdog/pause listeners are cleaned up in finally.45second watchdog,50MiB video limit, bounded GIF dimensions/frame count. No new dependency, provider request, native install or real-device acceptance. Native export reuses the existing local file/share path.
