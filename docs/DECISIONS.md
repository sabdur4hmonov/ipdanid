# Decisions

2026-10-04 (Asia/Tashkent)

- Portrait accuracy takes priority over thread consumption. Algorithm /4 has no stock penalty or stock stop; shortages are derived from actual sequence length plus existing wrap/waste/start allowances. The 20,000-line ceiling bounds computation and is explicitly reported as such. Coordinate-refinement stages bound evaluations to 200,000 and three sweeps, retain a rotating next-pin checkpoint, and do not claim global optimality.
- Manual face boxes and proportional eye/nose/mouth measurement bands replace any implied automatic face detection. Local target preparation is grayscale, feathered background simplification and bounded local contrast; it changes pixel tone, never facial geometry or identity. Users see original crop and exact target before generation. Portrait preparation is optional and resettable.
- Two-step lookahead may accept a locally worse connector when the combined continuous pair improves the objective. Refinement replaces an interior pin only when both legal neighbouring connections improve face-weighted fine/coarse optical error. Existing sequences are never edited in place; progress remains hash-bound. Multicolor coordinate refinement is not implemented.
- Exact-photo evidence is local-only under ignored output/portrait. The original stock was not exhausted at the reproduced failure. Same-material facial errors improved, but whole-image MSE and some edge errors may worsen. The higher-pin/finer-thread comparison is separately labeled; it is not a calibrated kit recommendation or a physical result.
- Optimizer and preview use one physical-area operator. A reusable deposition buffer preserves the prior pixel insertion order and coverage values; exact-photo replay reproduced the identical sequence hash after this speed improvement. The cache ceiling measures typed footprint buffers, not the application's entire memory footprint.
