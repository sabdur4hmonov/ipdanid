# Physical trial protocol - not performed

The software agent cannot assemble a kit. Numeric reconstruction error and screenshots are simulation/browser evidence only.

1. Record actual board dimensions/thickness, outline/pin coordinates, pin shaft/head dimensions, thread diameter/palette/spool lengths and material batch. Replace provisional profiles before declaring a kit compatible.
2. Generate a 400–700 step trial using a consented close portrait. Record image/sequence hashes, profile/engine version, estimates and allowances. Export this exact instruction.
3. Print at 100% with fit-to-page disabled. Measure each 50 mm ruler; photograph measurements. Align identical board-coordinate crosses. Verify pin IDs/orientation before drilling.
4. Assemble and explicitly confirm short intervals. Record actual time, thread consumption, tension, interference, breaks and ambiguous instructions. Test pause/resume and recovery at a repeated pin.
5. Photograph the result under uniform light with explicit consent. Compare to preview/source; record likeness, detail, contrast and failure modes without invented quality ratings.
6. Repeat rectangle/heart/light/multicolor; verify knots, available palette and wrap/waste assumptions. Publish a new calibrated profile version while preserving approved sequences.
